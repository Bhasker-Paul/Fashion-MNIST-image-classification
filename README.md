The goal of this project is to build a deep learning model that can accurately classify different clothing items. This project demonstrates:

Data preprocessing for image classification

Neural network model creation with Keras / TensorFlow

Model training, validation, and evaluation

Use of CNN (Convolutional Neural Network) for image recognition
Dataset Information

Dataset Name: Fashion-MNIST

Source: Keras datasets.fashion_mnist

Training Samples: 60,000 images

Test Samples: 10,000 images

Image Size: 28x28 pixels

Channels: 1 (grayscale)

Classes (Labels): 10
| Label | Class Name  |
| ----- | ----------- |
| 0     | T-shirt/top |
| 1     | Trouser     |
| 2     | Pullover    |
| 3     | Dress       |
| 4     | Coat        |
| 5     | Sandal      |
| 6     | Shirt       |
| 7     | Sneaker     |
| 8     | Bag         |
| 9     | Ankle boot  |
